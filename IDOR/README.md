# IDOR Research Notes

Personal research notes, methodologies, and lessons related to **Insecure Direct Object References (IDOR)** and **Broken Object Level Authorization (BOLA)**.

This folder is **not** a collection of lab writeups. Instead, it serves as a knowledge base built from blogs, research papers, cheat sheets, disclosed reports, and security articles.

---

## Purpose

The goal of this directory is to transform external security research into practical bug bounty methodology and a deeper understanding of authorization flaws.

---

## Topics Covered

- IDOR / BOLA fundamentals
- Authorization concepts
- Horizontal & Vertical privilege escalation
- Blind IDOR
- GraphQL IDOR
- API authorization flaws
- Mass Assignment
- Parameter Pollution
- Object references
- Identifier enumeration
- Attack chains leading to Account Takeover
- Real-world case studies
- Detection methodologies
- Prevention techniques
